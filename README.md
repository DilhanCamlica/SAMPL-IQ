# SAMPL-IQ

Un système de second brain dans Obsidian, piloté par IA (Claude Code). Une base de connaissance personnelle relationnelle, pensée comme une alternative plus complète à PARA.

Le nom vient des 8 dossiers maîtres : **A**toms, **P**eople, **S**ources, **P**rojects, **M**aps, **L**ogs, **I**ntentions, **Q**uestions. Anagramme : SAMPL-IQ, "Sample your IQ with your second brain".

## Ce que tu obtiens

- 8 types de notes reliés par wikilinks (pas d'arborescence thématique).
- Une doctrine complète et self-contained dans `_meta/` : capture, triage, imports, sessions, lifecycle, hygiène des tags.
- 4 skills Claude Code prêts à installer (`skills/`) : capture, triage, transcripts-to-inbox, youtube-import.
- Des dossiers vides prêts à remplir. Aucun contenu personnel.

## Démarrage

➡️ **Lis [`ONBOARDING.md`](./ONBOARDING.md).** C'est le guide de lancement complet : concept, pré-requis, installation pas à pas, architecture multi-appareils iCloud, capture mobile, et les flux de complétion.

Si tu utilises ce repo via "Use this template" sur GitHub, clone ton nouveau repo dans le dossier iCloud d'Obsidian, ouvre Claude Code dedans, et demande-lui de dérouler `ONBOARDING.md` avec toi (voir §9 du guide).

## Les règles d'interaction

`CLAUDE.md` à la racine définit comment une IA doit se comporter dans ce vault (garde-fous, ton, conventions de commit, règle wikilink stricte). Toute IA invoquée sur ce repo lit `ONBOARDING.md` puis `CLAUDE.md` en premier.
